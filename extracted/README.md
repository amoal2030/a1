# منصة خدماتي البرمجية (Khdamati Tech)

منصة شخصية احترافية متكاملة باللغة العربية لعرض خدمات تصميم وبرمجة المواقع الإلكترونية للمشاريع الصغيرة، المتاجر والمطاعم ومقدمي الخدمات بمساعدة أدوات الذكاء الاصطناعي.

---

## 🌟 مميزات المشروع
- **تقنيات قياسية نقية 100%:** مبني فقط باستخدام **HTML5 و CSS3 و Vanilla JavaScript** دون الحاجة إلى React أو Node.js أو أي إطار عمل معقد.
- **واجهة عربية كاملة (RTL):** خطوط عربية واضحة ومقروءة (Tajawal & Cairo) مع اتجاه سليم من اليمين إلى اليسار.
- **تخصيص فائق السهولة من ملف واحد:** يمكنك تغيير اسم المنصة، رقم الواتساب، الأسعار، الخدمات، ومعرض الأعمال من ملف `js/config.js` في ثوانٍ معدودة.
- **شفافية واحترافية:** توضيح صادق لأسلوب العمل كمطور مبتدئ يستفيد من الذكاء الاصطناعي دون ادعاءات مضللة.
- **باقة افتتاحية بقيمة 60 دولاراً:** عرض واضح ومحدد لموقع بسيط من 3 صفحات، مع توضيح صريح لما يشمله السعر وما لا يشمله.
- **معرض أعمال متكامل:** يشمل نماذج واقعية لمشاريع حقيقية (متجر تمور وعسل فاخر، صفحة هبوط لمخبز وكافيه، وموقع تعريفي لمكتب استشارات هندسية).
- **نموذج طلب خدمة تفاعلي وذكي:** يحسب التكلفة التقديرية فورياً، يتحقق من الحقول، ويرسل ملخص الطلب مرتباً ومباشراً إلى رقم واتساب الخاص بك.
- **أزرار واتساب نشطة:** زر عائم سريع وأزرار داخل بطاقات الخدمات والمشاريع تفتح محادثة مباشرة بنص مسبق الإعداد.

## ⚙️ كيفية تخصيص وتعديل بياناتك (في دقيقة واحدة)

افتح الملف `js/config.js` بأي محرر نصوص (مثل Notepad أو VS Code). ستجد جميع البيانات مع شروحات باللغة العربية:

### 1. تغيير رقم الواتساب والبريد الإلكتروني:
ابحث عن سطر `whatsAppNumber` و `email` في كائن `contact`:
```javascript
whatsAppNumber: "966541821068", // رقمك بالصيغة الدولية جاهز ويعمل مباشرة
email: "amoal2030@gmail.com",    // بريدك الإلكتروني المعتمد
```

### 2. تغيير اسم المنصة والشعار:
```javascript
siteName: "خدماتي البرمجية", // غيّر الاسم إلى ما ترغب به وسيتحدث في كامل الموقع
siteTagline: "تصميم وبرمجة مواقع حديثة للمشاريع الصغيرة بمساعدة الذكاء الاصطناعي",
```

### 3. تعديل سعر الباقة الافتتاحية:
```javascript
introPackage: {
  priceUSD: 60, // غيّر السعر هنا وسيتحدث فورياً في كامل الواجهة
  ...
}
```

### 4. إضافة أو تعديل مشاريع معرض الأعمال:
يمكنك ببساطة إضافة عنصر جديد إلى مصفوفة `projects` في `js/config.js` مع وضع صورتك في مجلد `assets/images/`.

## 💻 كيفية تشغيل الموقع محلياً على جهازك

الموقع مبني بملفات ثابتة تماماً (Static Files) وبالتالي **لا يحتاج لتثبيت أي برامج أو حزم إضافية**:

### الطريقة الأولى (الأسهل إطلاقاً):
- انقر نقراً مزدوجاً على ملف `index.html` ليفتح مباشرة في متصفحك (كروم، إيدج، سفاري، فايرفوكس).

### الطريقة الثانية (باستخدام خادم محلي للمطورين):
- إذا كنت تستخدم **VS Code**: افتح المجلد واضغط كليك يمين على `index.html` واختر **Open with Live Server**.
- أو عبر سطر الأوامر (Terminal) باستخدام Python:
  ```bash
  python3 -m http.server 3000
  ```
  ثم افتح في متصفحك: `http://localhost:3000`

## 🚀 كيفية رفع ونشر الموقع على استضافة مجانية

الموقع لا يتطلب أي قاعدة بيانات أو خادم Node.js، مما يجعله مؤهلاً للنشر المجاني السريع مدى الحياة:

### 1. الاستضافة عبر GitHub Pages (مجاناً تماماً):
1. أنشئ مستودعاً جديداً (New Repository) على GitHub باسم `my-portfolio`.
2. ارفع جميع ملفات هذا المجلد إليه.
3. ادخل على **Settings** > **Pages** > اختر فرع `main` واضغط **Save**.
4. سيصبح موقعك متاحاً خلال ثوانٍ على رابط: `https://yourusername.github.io/my-portfolio/`.

### 2. الاستضافة عبر Cloudflare Pages أو Netlify أو Vercel:
1. أنشئ حساباً مجانياً على [Netlify.com](https://www.netlify.com) أو [Cloudflare Pages](https://pages.cloudflare.com).
2. اسحب مجلد المشروع (Drag and Drop) إلى صفحة الرفع.
3. موقعك سيعمل فورياً مع شهادة أمان SSL مجانية وسرعة تحميل فائقة.

### 3. الاستضافة عبر لوحة تحكم cPanel / Hostinger:
1. ادخل إلى مدير الملفات (File Manager).
2. افتح مجلد `public_html`.
3. ارفع ملفات هذا المجلد كما هي داخل `public_html`.
4. افتح نطاقك الخاص وسيعمل الموقع على الفور.
